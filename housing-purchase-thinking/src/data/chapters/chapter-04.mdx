## 自分の資産を把握していない人は意外と多い

灰島との最初の面談で「住宅購入の思考法」に触れた翔平は，その内容を花に伝えます．しかし花からは「でも，具体的にはどうすればいいの？ 言っていることはわかるけど，それで私たちの予算が勝手に増えるわけではないでしょ」とシビアな反応が返ってきました．

たしかに灰島の言うことは正しそうだし，白濱は成功している．だけど，具体的にどうすればいいかはまだわからない──翔平はそんな思いを抱えながらも，灰島に連絡を取り，2回目の面談に向かいます．

## 思考法3：自分の資産を可視化せよ

灰島は2回目の面談で，「住宅購入のバランスシート」を紹介します．

<KeyConcept title="住宅購入のバランスシートとは">
企業の経営に必須と言われるバランスシート（貸借対照表）を，個人の住宅購入に応用したものです．このシートで明らかにできることを一言で表すと**「自分の資産の変化」**です．

バランスシートを使いこなせれば，以下のことが実現できます．

- 住宅購入に必要なお金や家計のリスクが見える化できる
- 「なんとなく買えそう」「まぁなんとかなるでしょ」がなくなる
- 数年後の自分の資産状況のシミュレーションができ，将来の不安を和らげられる
</KeyConcept>

灰島はファーストリテイリング（ユニクロ）と楽天グループのバランスシートを例に，「資産」「負債」「純資産」の3つの関係を説明します．

### 資産・負債・純資産の3つの関係

<Callout type="note" title="基本概念を押さえよう">
- **資産**：人・会社が持っているものすべて（現金・株式・不動産・車など）
- **負債**：誰かから借りているもの（借金など）
- **純資産**：純粋に（借りているものを全部返したときに）持っている資産

人や企業は純資産を少しでも増やすために日々活動しています．負債は必ずしも悪いものではなく，純資産を増やすために不可欠なものでもあるのです．
</Callout>

## 住宅購入バランスシートの3ステップ

灰島が用意したシートは3つのステップに分かれています．

### ステップ1：今の生活を簡単に整理して把握する

まずは自分の収支（PL＝損益計算書に相当）を把握します．灰島に促されて翔平が記入した青井家の収支は以下の通りです．

| 支出項目 | 金額 | 収入項目 | 金額 |
|---|---|---|---|
| 税金・保険料 | 12.5万円 | 額面給与 | 50万円 |
| 家賃 | 10万円（妻と分担） | | |
| 水道光熱費 | 2万円 | | |
| 通信費 | 1万円 | | |
| 食費・交際費 | 10万円 | | |
| 趣味・娯楽費 | 5万円 | | |
| 保険 | 1万円 | | |
| その他 | 3万円 | | |
| 余剰資金 | 5.5万円 | | |
| **合計** | **50万円** | **合計** | **50万円** |

<Callout type="tip" title="収支把握のポイント">
家を買うときに「家にかかるお金」を調べる人は多いですが，「自分の今のお金の流れ」を把握できている人は少なく，あとになって意外と苦しいということがよく起こります．また，多くの人は収入を大きく，支出を小さく書きがちです．
</Callout>

### ステップ2：バランスシートで自分の資産を可視化する

次に，預金や保有している証券を整理して「見える資産」を把握します．

| 資産 | 金額 | 負債・純資産 | 金額 |
|---|---|---|---|
| 現金（預金） | 450万円 | 借り入れなど | 0円 |
| 有価証券 | 50万円 | 純資産 | 500万円 |
| **合計** | **500万円** | **合計** | **500万円** |

自分の「見える資産」がどうなっているのかを知ることが大事です．このあと家を買った場合の変化を見ていくのに，そもそも自分の見える資産がわかっていないと，単純に「貯金が減った」「借金が増えた」とネガティブになってしまいます．

### ステップ3：バランスシートで家を買ったらどうなるか計算する

<KeyConcept title="住宅購入直後のバランスシート">
5000万円の家をフルローンで購入し，諸費用350万円を支払った直後のバランスシートは以下のようになります．

| 資産 | 金額 | 負債・純資産 | 金額 |
|---|---|---|---|
| 現金（預金） | 100万円 | 住宅ローン残債 | 5000万円 |
| 有価証券 | 50万円 | | |
| 住宅 | 5000万円 | 純資産 | 150万円 |
| **合計** | **5150万円** | **合計** | **5150万円** |

資産がいきなり5000万円以上になります（負債も同じですが）．家はただの住むところではなく，立派な資産なのです．
</KeyConcept>

灰島はこう説明します．「**見えるお金は減っているのに，資産は増えている**──住宅購入の本質はここにあります」

翔平はこの言葉で頭のなかのパズルがハマるような感覚を覚えます．これまで賃貸の延長線上としてしか住宅購入を考えられていなかったのではないか──ひたすらに「お金を払って住むところを探す」だけを考えていたことに気づきます．

<KeyConcept title="10年後の資産変化">
金利1%で10年後のバランスシートを見ると，住宅価値が年間1%ずつ下がっても純資産は増加しています．

| 資産 | 金額 | 負債・純資産 | 金額 |
|---|---|---|---|
| 現金（預金） | 100万円 | 住宅ローン残債 | 3745万円 |
| 有価証券 | 50万円 | | |
| 住宅 | 4522万円 | 純資産 | 927万円 |
| **合計** | **4672万円** | **合計** | **4672万円** |

購入前の純資産500万円が，購入直後に150万円に減少しますが，10年後には927万円まで増加します．これはローンの返済ペースよりも家の価値の下がるペースが遅いからです．
</KeyConcept>

<Callout type="important" title="資産性が重要な理由">
もしローンの返済ペースよりも家の価値が下がるペースのほうが早ければ，それは資産性が低い物件と言わざるを得ません．人生100年時代にずっと同じところに住むのは現実的ではなく，子供が大きくなったり自分たちが年老いたりしたときの住み替えも考慮する必要があります．「買い物して，はい終わり」ではなく，買ったその先の人生でどう運用していくかを考えることが大切です．
</Callout>

## 住宅ローンの基礎

灰島は住宅ローンの基礎も解説します．住宅ローンを比較する3つの軸は以下の通りです．

### 1. 金利

ずっと金利が変わらない**固定金利**と，借りている最中に金利が変わる**変動金利**の2種類があります．

### 2. 保険

住宅ローンを借りるためには，**一般団体信用生命保険（一般団信）** と**火災保険**への加入がほぼ必須です．

一般団信はローン利用者が死亡もしくは所定の高度障害状態になった際にローン残債が全額なくなる保険で，これに入っていれば最低限の生命保険は不要になります．追加でがん保障や疾病保障のオプションも選択できます．

### 3. 初期費用

基本は借入金額の2.2%（税込）と契約時の印紙代がかかります．ただし，初期費用を抑えた商品もあり，その場合は金利が約0.25%程度高くなることが多いです．

<Callout type="tip" title="初期費用と金利のトレードオフ">
短期（10年以内）で住み替えや売却を想定している場合は初期費用を抑えたほうがお得になります．それ以上住む想定の場合は，初期費用を払っても低金利を選んだほうが得です．必ずシミュレーションをして判断しましょう．
</Callout>

## 自分の価値観と家族の価値観

灰島との2回目の面談を終えた翔平は，灰島から「次回は奥様も一緒にどうか」と提案されます．次回のテーマは「家探しに疲れてしまったときの考え方」と「現実との向き合い方」です．

しかし，花にこのことを伝えると「また買えるかもって思って疲れちゃいそう」「元不動産会社の人なんでしょ？ 自分の利益になることしか言ってくれないんじゃないの？」と強い抵抗を示されます．

<Callout type="note" title="夫婦間の温度差は自然なこと">
住宅購入において，パートナー同士の意見や温度感が異なることは非常に一般的です．一方が前向きになるほど，もう一方が慎重になるという構図はよく見られます．大切なのは，お互いの気持ちを尊重しながらコミュニケーションを取り続けることです．
</Callout>

翔平が粘り強く説得しようとしますが，花は「もう家のこと考えたくない」と怒り出し，二人は激しい口論に発展してしまいます．

## コラム：3年間待つあいだのコストと値下がり期待

住宅購入において「待つことのコスト」は大きな要素です．

仮に現状の家賃が夫婦で15万円で，5000万円の住宅購入を検討している場合，1年待つと賃料は180万円になります．つまり，5000万円から180万円（3.6%）以上値下がりしてようやくトントンです．ローン完済が1年遅れるリスクや健康状態の悪化リスクも考慮すると，実質的には5%程度以上の値下がりが必要です．

2000年以降の日本で不動産価格が下落した時期を振り返ると：

- **リーマンショック**：6.3%（2008年5月→2009年4月）
- **東日本大震災**：0.9%（2011年1月→2012年2月）

リーマンショック級の大きな出来事でも，年間5%の下落には達していません．「値下がりを待っている」ことがいかに合理的でない判断であるかがわかります．
